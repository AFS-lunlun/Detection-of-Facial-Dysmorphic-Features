# Synthetic examples

All identifiers, labels, probabilities and relative filenames in this directory
are artificial. They illustrate input schemas and statistical analysis commands.
No participant records or facial photographs are included.

The image paths in the manifest are placeholders. `audit` without `--data-root`
checks group allocation; image-byte checks require privately stored, authorized
image files. Synthetic predictions intentionally include classification errors.
Results generated from these examples are not clinical findings.
