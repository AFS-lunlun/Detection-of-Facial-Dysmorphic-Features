# 面容分类模型统计分析

本项目提供二分类面容模型的数据划分与统计评价工具。输入真实标签和模型输出的
正类概率后，可生成评价指标、ROC、混淆矩阵、校准描述及相关图表。

## 功能

- 按类别进行患者级训练／验证划分，同一患者全部图像归入同一集合。
- 检查患者跨集合重叠，以及可选的完全重复图片检查。
- 分别进行图像级和患者级评价。
- 计算准确率、精确率、敏感度、特异度、F1、PPV、NPV、AUC及Brier分数。
- 采用患者平均预测概率汇总，计算患者级bootstrap置信区间。
- 比较相同评价样本上的模型指标。
- 计算明确标注假设条件的患病率与PPV情景分析。

本项目支持数据划分、统计评价及研究图表输出。

## 使用

Python 3.10及以上可执行数值分析。作图需安装requirements.txt中的依赖。
完整参数与命令见英文README。

```bash
python analysis.py --help
python analysis.py evaluate --predictions examples/synthetic_predictions.csv --unit participant --bootstrap 200 --output outputs/example
```

真实分析需输入模型导出的正类概率，标签1表示正类。sample_id和group_id应为随机分配、
无个人含义的标识，同一患者的group_id必须一致。身份映射表保留在仓库外。

公开示例数据全部虚构，仅用于说明输入格式和运行方法，不是研究结果。
本仓库不包含真实患者记录、照片、个体预测数据、模型权重或个人电脑路径。

## 分析说明

- 默认按类别将约30%的患者分到验证集；同一患者所有照片随患者一起分配。
- 改变分区后，应按新训练集训练模型，再对相应验证集生成预测。
- 患者级评价采用同一患者各照片正类概率的算术平均，每位患者权重相同。
- bootstrap按类别重采样患者，固定预测结果，不包含重新训练或模型选择的不确定性。
- 类内少于2名患者时不提供区间；完美指标可能产生退化区间，不能解释为没有总体不确定性。
- 使用验证集选checkpoint后再报分仍是内部开发评价，不因计算CI而成为独立测试。
- PPV情景分析须明确敏感度、假设特异度和目标阳性比例，不能替代实测临床PPV。
